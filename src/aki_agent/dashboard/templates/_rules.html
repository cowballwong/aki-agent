Standing instructions for your assistant. It reads them at the start of every session and follows them, and they outrank its own judgement about what would be more helpful.

These are followed, not enforced. That is the difference between this page and Safety: safety refuses a short list of unrecoverable commands in code, whatever anybody says, and cannot be changed. A house rule is an instruction to a careful assistant.

Where a rule happens to be true in code as well, it says so below — because “it has been told” and “it cannot” are different promises, and deciding how much to leave it doing unattended means knowing which one you have.
