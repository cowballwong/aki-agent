Where do I find that address?

Google Calendar — Settings › the calendar in the left list › Integrate calendar. That page offers four things and you want the last one: Secret address in iCal format (click the eye to reveal it).

  • Public URL to this calendar — a web page, not data.
  • Embed code — HTML for a website.
  • Public address in iCal format — the right format, but only works if you make the whole calendar public to the world.
  • Secret address in iCal format — the only one that works without publishing anything. This one.

Outlook.com — Settings › Calendar › Shared calendars › Publish a calendar, then copy the ICS link (not the HTML one).

Apple / iCloud — the Calendar app › right-click the calendar › Share Calendar › tick Public Calendar, then copy the address.

Fastmail — Calendar settings › the calendar › Secret URL.

Whichever you use, that address is a key: anyone holding it can read the whole calendar without a password. If you ever paste it somewhere by mistake, your calendar's settings page has a Reset that makes the old one dead immediately.
