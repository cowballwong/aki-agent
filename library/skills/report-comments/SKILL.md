# Report comment drafting

## What each comment needs

Something specific the student actually did · what it shows · one concrete
thing to work on next. A comment that could be about any child in the class
is one the parent knows is boilerplate.

## Rules

- **Draft from evidence** — marks, work, the teacher's own notes. Never
  invent an observation.
- **Vary the openings.** Thirty comments beginning "X has had a good term"
  reads as what it is.
- Check against last term's comment: repeating the same target verbatim
  either means nothing changed — say that honestly — or that nobody read it.
- Keep the school's register and length limit.

## Sensitive ground

Behaviour, effort and ability are three different things and conflating them
is what makes a report unfair. Say what was observed.

## Never

Never finalise. These are drafts for the teacher, who knows the child.
