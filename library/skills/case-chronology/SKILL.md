# Case chronology

## Each line

Date · what happened · the document that evidences it · reference.

Nothing goes in without a document reference. A chronology is used to check
recollection against the record, so an entry from recollection defeats the
purpose.

## Order and precision

Strict date order. Where only a month is known, say so rather than choosing a
day. Where two documents disagree on a date, show both.

## What to flag separately

- gaps where something clearly happened but no document is on file
- documents that are undated
- anything that appears to have been created after the fact

## Never

Do not characterise. "Letter from X denying liability" is a description;
"X refused to accept responsibility" is an argument, and it does not belong
here.
