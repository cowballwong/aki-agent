# Intake form to record

## What to do

Read the form — typed, handwritten, or a photo of one — and produce a
structured record with the fields the user's own system uses. Ask once what
those fields are; then keep using them.

## What to be careful about

- **Copy exactly.** Names, phone numbers, reference numbers and dates are
  copied character by character, never tidied. A "corrected" name is a record
  that will not match anything.
- **Say what is illegible** rather than guessing. One field marked unreadable
  is fixable; a plausible wrong number is not.
- **Flag what is missing** against the fields that matter, so it can be
  chased while the person is still on the phone.

## Where it goes

Into the user's own record. If the form contains health, financial or
identity information, say plainly where it is being stored — on this machine
— and do not copy it anywhere else.

## Afterwards

Offer the next step the user's process needs: a confirmation to send, a first
appointment, a file to open.
