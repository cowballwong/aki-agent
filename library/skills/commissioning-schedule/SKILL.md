# Commissioning and maintenance schedule

## Commissioning

For each system: what has to be tested, in what order, what has to be
complete first, who witnesses, and what document proves it.

Sequence matters more than dates here — a test run before its prerequisite is
a test that will be run twice.

## Handover pack

Track: test records, O&M manuals, as-built drawings, warranties, spares,
training. This list is where handovers stall, and it stalls in the same place
every time: documents nobody assigned to anybody.

## Maintenance

Turn the O&M requirements into dated, recurring obligations and put them on
the deadline list — including statutory inspections, which do not wait for
the building to be occupied.

## Never

Never record a test as witnessed unless the record says who witnessed it.
