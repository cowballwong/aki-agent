# Client due diligence pack

## What this does

Runs the firm's own checklist and tracks what is held, what is missing and
what expires. It does not decide whether the client is acceptable — that is a
judgement with regulatory weight and a named person makes it.

## Track

Document · who it relates to · date obtained · expiry · certified or copy ·
where it is stored.

## What to watch

- documents expiring, which quietly make a file non-compliant
- beneficial ownership evidence, which is where most files are thin
- anything that changed since onboarding — a new director, a new address

## Handling

This is identity and financial information. Say where it is stored — on this
machine — and never copy it elsewhere, never include it in a draft email, and
redact reference numbers in anything that leaves the file.

## Never

Never form or record a view on whether a client is high risk. Assemble, track,
and hand to the person whose responsibility that is.
