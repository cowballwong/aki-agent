# Renewal run

## The list

Client · policy · expiry · premium last year · changes known · status ·
last contact.

Sort by expiry. Start earlier than feels necessary — a renewal chased in the
last week is a renewal that lapses or is placed badly.

## For each

- what changed in the client's circumstances since last time, from the file
- whether the sum insured is still right — the single most common failure,
  and the one that hurts at claim time
- whether re-quoting is worth it, and what that costs in time

## Non-responses

Track them explicitly, with how many attempts and by what channel. A policy
that lapses because three emails went unanswered is still a problem, and the
record of attempts is what protects the broker.

## Never

Never bind, renew or cancel anything. Prepare and hand over.
