# Drawing and specification cross-check

## What to compare

- drawing against specification: materials, grades, finishes, tolerances
- drawing against drawing: the same element on plan, section and detail
- schedules against the drawings they schedule
- revision numbers: is every sheet from the same issue?

## Report a conflict properly

State both versions, with sheet number and revision for each, and say what
the difference would mean on site. "Slab thickness 200 on GA-104 Rev C, 225
on S-210 Rev B — 25mm affects finished floor level throughout" is actionable.
"Discrepancy noted" is not.

## Order the findings by cost of being wrong

Something that changes a pour, a fabrication order or a lead-in item goes
first. A finish discrepancy goes last, however obvious it is.

## Never

Do not resolve the conflict. Present it to the person whose decision it is.
