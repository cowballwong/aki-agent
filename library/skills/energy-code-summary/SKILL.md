# Energy code compliance summary

## What this does

Reads the code edition the user holds and builds the list of requirements
that apply to this project, then tracks what evidence exists for each.

## The list

Requirement · which system it applies to · what evidence is needed · what we
have · gap.

## Rules

- **Quote the code, do not summarise it from memory.** Name the edition and
  the clause. If the user has not supplied the code, say so and ask for it —
  an energy requirement misquoted from memory is a design decision made on
  bad information.
- Distinguish *design* compliance from *installed and verified* compliance.
  They are checked at different times by different people, and conflating
  them is how a project arrives at completion with no evidence.

## Output

Gaps first, with who closes them and when. Then the evidence register.
