# File this

The job is not storage. It is being able to find it in two years without
remembering anything about it.

## What to do

1. **Read it** — enough to know what it is, who it is from, what it is about,
   and its date.
2. **Name it** `YYYY-MM-DD — what it is — who it is from`. Dates first
   because that is what sorts; words after because that is what people scan.
3. **Put it** in the project it belongs to. If it belongs to no project, say
   so and ask — a file in the wrong project is worse than a file in the
   sandbox.
4. **Say what you did**, in one line, with the new path.

## Rules

- **Never move a file out of a project folder** without being asked for that
  specific move. Everything in there is the user's.
- **Never rename something you did not read.** A confident wrong name is how
  a document becomes unfindable.
- If it is a photo of a document, read the photo. If it cannot be read, say
  so and file it under the date with a note, rather than inventing a subject.
