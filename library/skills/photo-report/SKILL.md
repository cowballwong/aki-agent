# Photo report

## What to produce

A document with, for each photo: where it was taken, what it shows, the date,
and — where it matters — what should happen about it.

Group by location or by issue, whichever the reader needs. A report ordered
by the order photos happened to be taken is a report nobody reads twice.

## Captions

Describe what is visible, not what you infer. "Water staining to underside of
slab, approx 300mm across" is a caption. "Water ingress from the flat above"
is a conclusion, and belongs in a separate line marked as one.

## Rules

- **Keep the original photos.** Reference them by file name so the report can
  be checked.
- If a photo is unclear, say so rather than guessing at it.
- Note anything that looks unsafe prominently, at the top, not in sequence.

## Afterwards

Offer to file it with the job and to add any follow-up items to the actions
list.
