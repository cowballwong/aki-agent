# Stock count reconciliation

## The output

Item · counted · expected · variance · value of variance.

Sorted by value of variance, not by item code. The list is read to find the
problems and there are usually five that matter out of three hundred lines.

## Rules

- **Never adjust a count to match the system.** The count is the observation;
  the system is the record. A discrepancy is information.
- Separate variances with a likely explanation (uninvoiced delivery, sale not
  rung through) from those without.
- Note items counted in a different unit from how they are recorded, which is
  the most common false variance.

## Afterwards

Offer: the adjustment list for somebody to approve, and the recount list for
anything large enough to be worth checking twice before adjusting.
